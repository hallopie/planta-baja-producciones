# Planta Baja Producciones
### hallopie.github.io/planta-baja-producciones

Estudio de arte y producción audiovisual.  
Este repositorio es el archivo público de un experimento en curso.

---

## La hipótesis

> "Un artista con criterio y visión puede usar inteligencia artificial como herramienta de producción para crear obra auténtica — sin que la tecnología sustituya el proceso creativo humano. Solo lo hace más rápido, más barato y más accesible."

## Qué vive aquí y qué no

**Sí se publica:**
- El proceso de producción — decisiones, iteraciones, criterios
- Capturas y comparativas antes/después
- Videos de prueba (embeds de YouTube no listados)
- El diario de avances por proyecto

**No se publica:**
- Guiones completos ni diálogos
- Prompts específicos detallados
- Biblias visuales completas
- Material de investigación del documental (hasta distribución)

La regla: documenta el qué y el por qué. No el cómo exacto.
